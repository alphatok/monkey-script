脚本安装向导

全局字体 / 元宝 / DeepSeek / Grok / X / 小红书 页面增强

安装步骤（两个脚本通用）
1
安装 Tampermonkey 扩展
如果未安装，先去 Chrome 商店 或 Firefox 商店 安装。安装后浏览器右上角会出现 Tampermonkey 图标。
2
开启必要权限
在浏览器地址栏输入 chrome://extensions（Firefox 输入 about:addons）→ 找到 Tampermonkey → 点击"详情" → 打开以下两个开关：
• 允许访问文件网址（本地打开时需要）
• 允许读取和更改网站数据 → 选择"在所有网站上"
3
在下面选择要装的脚本，点安装
Tampermonkey 会弹出确认窗口显示脚本内容，点击"安装"即可。
4
验证安装
打开对应站点，页面右下角会出现圆形的悬浮球（DeepSeek 是齿轮设置按钮），说明脚本已生效。
⚠️ 检测到本地文件打开
浏览器安全限制导致 file:// 下的脚本无法被 Tampermonkey 处理。三选一：
• 按 Step 2 开启"允许访问文件网址"后刷新本页；
• 或在脚本目录运行 python3 serve.py，再访问 http://localhost:8080/index.html；
• 或直接用下面每个脚本的 GitHub 在线地址安装。

扇贝单词助手

web.shanbay.com 单词学习页 + 阅读页：朗读 + 英文排版

点一下英文例句 / 引文 / 短语就朗读，本地神经语音 Kokoro（不是系统那种机器音）
阅读页点哪句读哪句，「朗读全文」按段连读；缩写（U.S. / Mr.）不会被切错句
正文里三个小喇叭：句尾读单句、段尾读整段、右下角读全文
阅读页正文按英文报刊排版：衬线字体 19px / 行高 1.72 / 段间距一行 / 行长约 70 字符，并补回句间缺失的空格
WebGPU 加速，一句约 0.3 秒出声；首次需下载 310MB 模型，之后完全离线
右下角齿轮打开设置：引擎、9 种音色、语速 0.6x～1.3x、悬停预生成
生成的音频存本地，重复播放零等待；正在读的句子淡绿高亮，再点或 Esc 停止
例句 14px 灰字 → 17px 深色；每日一句引文 14px → 18px，行高一起放开
划词选中时不会误读；深色主题自动跟随站点配色变量
