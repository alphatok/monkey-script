元宝助手

腾讯元宝聊天页面增强工具

Enter 发送消息，Shift+Enter 换行
页面加载后自动聚焦输入框
自动隐藏底部下载横幅
双击聊天消息复制内容
默认进入临时会话（可手动取消）

安装步骤
1
安装 Tampermonkey 扩展
如果未安装，先去 Chrome 商店 或 Firefox 商店 安装。安装后浏览器右上角会出现 Tampermonkey 图标。
2
开启必要权限
在浏览器地址栏输入 chrome://extensions（Firefox 输入 about:addons）→ 找到 Tampermonkey → 点击"详情" → 打开以下两个开关：
• 允许访问文件网址（本地打开时需要）
• 允许读取和更改网站数据 → 选择"在所有网站上"
3
点击下面的按钮安装脚本
如果 Tampermonkey 正常工作，会弹出一个确认窗口，显示脚本内容，点击"安装"即可。
4
验证安装
访问 https://yuanbao.tencent.com/chat/ ，在输入框按 Enter 测试是否能发送消息。
安装到 Tampermonkey

按钮打不开？改用在线地址安装（不需要本地服务器）：
raw.githubusercontent.com/.../yuanbao-helper.user.js

⚠️ 检测到本地文件打开
浏览器安全限制导致 file:// 下的脚本无法被 Tampermonkey 处理。二选一：
• 按 Step 2 开启"允许访问文件网址"后刷新本页；
• 或在脚本目录运行 python3 serve.py，再访问 http://localhost:8080/index.html；
• 或直接用上面的 GitHub 在线地址安装。
